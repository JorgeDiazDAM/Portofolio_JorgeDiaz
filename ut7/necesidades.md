# UT7 - Elaboración de documentación técnica

## 7.2 Necesidades de software

Las necesidades de software son los programas que necesitamos para realizar diferentes tareas.

### Tipos de aplicaciones

| Necesidad | Programa |
|---|---|
| Escribir documentos | Word |
| Realizar cálculos | Excel |
| Crear presentaciones | PowerPoint |
| Navegar por Internet | Chrome |
| Programar | Visual Studio Code |

### Requisitos del software

Antes de instalar un programa debemos comprobar:

- Sistema operativo.
- Memoria RAM.
- Espacio disponible.
- Compatibilidad.
- Licencia.

### Comprobar las características del equipo

```cmd
systeminfo
```

### Selección de programas

Debemos elegir aplicaciones que se adapten a nuestras necesidades y que sean compatibles con el ordenador.

> [!TIP]
> Descarga siempre los programas desde sus páginas oficiales.

## Conclusión

Elegir correctamente el software permite aprovechar mejor los recursos del ordenador.
