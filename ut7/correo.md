# UT7 - Elaboración de documentación técnica

## 7.4 Correo electrónico y mensajería

El correo electrónico permite enviar y recibir mensajes y archivos por Internet.

### Partes de un correo

- Remitente.
- Destinatario.
- Asunto.
- Mensaje.
- Archivos adjuntos.

### Protocolos de correo

| Protocolo | Función |
|---|---|
| SMTP | Enviar correos. |
| POP3 | Descargar correos. |
| IMAP | Sincronizar correos. |

### Mensajería instantánea

Algunas aplicaciones conocidas son:

- WhatsApp.
- Telegram.
- Microsoft Teams.
- Discord.

### Ejemplo de correo

```text
Para: alumno@ejemplo.com
Asunto: Entrega del trabajo

Adjunto el documento solicitado.
```

> [!WARNING]
> No abras enlaces ni archivos sospechosos.

## Conclusión

El correo y la mensajería facilitan la comunicación y el intercambio de información.
