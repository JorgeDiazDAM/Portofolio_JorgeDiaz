# UT7 - Elaboración de documentación técnica

## 7.6 Búsqueda de documentación

Consiste en localizar información técnica para aprender y resolver problemas informáticos.

### Fuentes de información

- Páginas oficiales.
- Manuales técnicos.
- Foros especializados.
- Tutoriales.
- Documentación de fabricantes.

### Buscadores y recursos

| Recurso | Utilidad |
|---|---|
| Google | Búsqueda general. |
| Bing | Buscar información. |
| Microsoft Learn | Documentación Microsoft. |
| MDN | Documentación web. |
| Stack Overflow | Consultas técnicas. |

### Operadores de búsqueda

| Operador | Función |
|---|---|
| " " | Buscar frases exactas. |
| site: | Buscar dentro de una web. |
| filetype: | Buscar archivos concretos. |

### Ejemplo de búsqueda

```text
site:docsify.js.org instalación Docsify
```

### Comprobar la información

Debemos revisar el autor, la fecha y la fiabilidad de las fuentes.

> [!TIP]
> Es recomendable consultar primero las páginas oficiales.

## Conclusión

Saber buscar documentación técnica es fundamental para resolver problemas y aprender nuevas tecnologías.
