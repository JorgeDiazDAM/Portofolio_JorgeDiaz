
# UT7 - Elaboración de documentación técnica

## 7.1 Clasificación y licencias

El software es el conjunto de programas que permiten realizar tareas en un ordenador.

### Tipos de software

| Tipo | Ejemplo |
|---|---|
| Sistema | Windows |
| Aplicación | Word |
| Programación | Python |

### Tipos de licencias

- **Libre:** permite modificarlo según su licencia.
- **Propietaria:** tiene restricciones de uso.
- **Freeware:** es gratuito.
- **Shareware:** permite probarlo.

### Ejemplo práctico

```cmd
systeminfo
```

> [!NOTE]
> Las licencias establecen las condiciones de uso del software.

## Conclusión

Es importante conocer las licencias para utilizar los programas correctamente.
