# UT7 - Elaboración de documentación técnica

## 7.5 Transferencia de ficheros

La transferencia de ficheros consiste en enviar archivos entre dispositivos mediante una red o Internet.

### Métodos de transferencia

| Método | Función |
|---|---|
| FTP | Transferir archivos. |
| SFTP | Transferencia segura. |
| USB | Transportar archivos. |
| Nube | Guardar archivos online. |
| Correo | Enviar adjuntos. |

### Servicios en la nube

- Google Drive.
- OneDrive.
- Dropbox.
- iCloud.

### Copiar archivos en Windows

Podemos utilizar CMD para copiar archivos entre carpetas.

```cmd
copy documento.txt C:\Documentos\
```

### Seguridad en las transferencias

Es importante utilizar conexiones seguras y comprobar los archivos descargados.

> [!TIP]
> SFTP permite transferir archivos mediante una conexión protegida por SSH.

## Conclusión

La transferencia de ficheros permite compartir información de forma rápida y sencilla.
