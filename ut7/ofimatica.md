# UT7 - Elaboración de documentación técnica

## 7.3 Documentación técnica y ofimática

La documentación técnica explica cómo funciona, se instala y se utiliza un sistema.

### Tipos de documentación

- Manuales de usuario.
- Guías de instalación.
- Manuales técnicos.
- Documentación de mantenimiento.

### Herramientas ofimáticas

| Aplicación | Función |
|---|---|
| Word | Crear documentos. |
| Excel | Realizar cálculos. |
| PowerPoint | Crear presentaciones. |
| Access | Gestionar bases de datos. |
| Writer | Crear documentos. |

### Formatos de archivo

| Formato | Uso |
|---|---|
| DOCX | Documentos. |
| XLSX | Hojas de cálculo. |
| PPTX | Presentaciones. |
| PDF | Documentos para compartir. |

### Exportar documentos

```text
Archivo → Exportar → PDF
```

> [!NOTE]
> La documentación debe ser clara, ordenada y fácil de entender.

## Conclusión

Las herramientas ofimáticas facilitan la creación de documentación profesional.
