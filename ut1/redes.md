# UT1 - Hardware y redes

## Redes informáticas

Una red informática conecta dispositivos para compartir información y recursos.

### Tipos de redes

| Tipo | Característica |
|---|---|
| PAN | Red personal. |
| LAN | Red local. |
| MAN | Red de una ciudad. |
| WAN | Red de larga distancia. |

### Topologías de red

- **Estrella:** conexión a un punto central.
- **Bus:** comparten un cable.
- **Anillo:** forman un circuito.
- **Malla:** tienen varias conexiones.

### Dispositivos de red

| Dispositivo | Función |
|---|---|
| Router | Conecta redes. |
| Switch | Conecta equipos. |
| Punto de acceso | Proporciona Wi-Fi. |

### Comandos de red

```cmd
ipconfig
ping 8.8.8.8
```

> [!TIP]
> El comando `ipconfig` permite consultar la configuración de red.

## Conclusión

Las redes permiten conectar dispositivos y compartir información.
