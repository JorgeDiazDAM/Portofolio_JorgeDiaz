# UT1 - Hardware y redes

## Hardware y componentes informáticos

El hardware es el conjunto de componentes físicos de un ordenador.

### Componentes internos

| Componente | Función |
|---|---|
| CPU | Procesa información. |
| RAM | Guarda datos temporalmente. |
| Placa base | Conecta los componentes. |
| SSD | Almacena archivos. |
| GPU | Procesa gráficos. |

### Periféricos

- **Entrada:** teclado y ratón.
- **Salida:** monitor e impresora.
- **Entrada y salida:** pantalla táctil.

### Consultar información del equipo

```cmd
systeminfo
```

> [!NOTE]
> El hardware son todas las partes físicas que podemos tocar de un ordenador.

## Conclusión

Conocer el hardware permite identificar los componentes y comprender cómo funciona un ordenador.
